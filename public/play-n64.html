Play Mario Kart 64 on your Chromebook

This runs the N64 game directly in Chrome using EmulatorJS/WebAssembly. It does not run the Xbox 360 MKart360 XEX, so it does not need Xenia or a cloud GPU.

Choose a .z64 or .n64 ROM that you legally obtained. The file is passed directly from your browser to the emulator and is not uploaded to this server by this page.
